# Gimbal CAD downloads

## Start with the base and azimuth drive

**[Download the assembled base as a ZIP](Gimbal_Base_Assembly_DOWNLOAD.zip)**. Extract `Base_Subassembly.step`; it contains eleven positioned components in a named AP214 assembly hierarchy. Open it in Solid Edge using its STEP assembly import option, then save the imported assembly as a Solid Edge `.asm` file. Solid Edge's native assembly extension is `.asm` (not `.assm`). A native Solid Edge file cannot be generated in this Linux workspace. For a FreeCAD review copy, download [Base_Subassembly.FCStd](Base_Subassembly.FCStd).

Download **[Base_Assembly_Only.zip](Base_Assembly_Only.zip)** for eleven separate STEP parts, a named base assembly STEP, a FreeCAD review assembly, and a step-by-step guide. You can also read the [assembly guide](Base_Assembly_Guide.pdf), [axial section](Base_Axial_Section.png), and [exploded view](Base_Exploded_View.png) before downloading.

## Full revised gimbal

Download **[Gimbal_CAD_v2_With_Base_Assembly.zip](Gimbal_CAD_v2_With_Base_Assembly.zip)** for all 31 STEP parts and the base subassembly. Use this revision when continuing to the fork arms; its base mounting patterns have been corrected.

The original `Gimbal_SolidEdge_STEP_Package.zip` is retained as the earlier 30-part concept. All geometry is provisional and image-derived. Bearings, motors, gear teeth, shaft/hub torque connection, fits, fasteners and structural performance need specifications before physical construction. Solid Edge can open the STEP files and save individual parts as `.par`.
